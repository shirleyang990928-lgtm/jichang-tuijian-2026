## 常见问题

**机场是什么？**
机场是提供多节点订阅服务的商家，你用 Clash、小火箭等客户端导入它给的订阅链接就能用。

**第一次买应该买多久？**
月付。导入成功、晚高峰用过一周再决定要不要买长期。

**优惠码怎么用？**
在官网注册后进入结算页，有一个优惠码输入框，手动填入后点验证，折扣以结算页显示为准。

**为什么这里不写价格和速度？**
价格随活动变化很快，写死会误导人；速度和你所在地区、时段关系很大，任何测速数字都不代表你用起来的体验。两项都请以官网和自己月付试用为准。

**机场跑路了怎么办？**
所以才建议月付、不囤年付、留一个备用机场。本榜单每周二复核一次，发现异常会写进更新记录。
